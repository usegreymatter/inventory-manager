# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, give and accept constructive feedback, and focus on what is best for the community. Harassment, insults and personal attacks are not acceptable.

Report unacceptable behaviour privately to the maintainers using the private reporting route in [SECURITY.md](SECURITY.md). Reports are handled confidentially.
