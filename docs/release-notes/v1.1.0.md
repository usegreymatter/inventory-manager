# Inventory Manager v1.1.0

2026-11-20 · Free, open-source, offline reorder planner.

## Download and open

Download **stock-runway-1.1.0.html** from the [v1.1.0 release assets](https://github.com/usegreymatter/inventory-manager/releases/tag/v1.1.0). Double-click the downloaded HTML, or choose **Open with → your browser**. No account, server or install is needed. The download runs offline; imported files stay on your device. The source ZIP and a separate 1,000-product synthetic demo are also release assets. Check downloads against SHA256SUMS.

## What changed

- **Simple worklist** is the first-device default: six decision columns, Low/Medium/High risk tiers and an order-focused list. **Show detail** reveals the chart, settings and expanded columns. Risk is a model estimate, not a guarantee.
- **Why this amount** explains the purchase ledger in the product view. Decimal display rounding is explicit; exact values remain in JSON. Python CLI `--explain` adds the readable explanation to CSV and `--json` includes the exact ledger.
- **Input review** checks stock meaning, reserved allocations, incoming supply, units, missing sales and incomplete/future months before showing orders. **Show orders anyway** acknowledges warnings; it does not repair data. Risky-file acknowledgement is not remembered.
- **Multi-sheet and warehouse safeguards** preserve joined incoming and contributor provenance, net reserved stock by SKU, require named-sheet confirmation before summing stock, and flag blank-location duplicates or conflicting units/lead times. Leading blank months before first recorded sales are disclosed as new-product history, not silently treated as missing cells.
- **Persistent warnings** keep an affected-product summary visible, retain product/row warnings and allow only session-local summary dismissal. Informational metadata differences are compact rather than a repeated review gate.
- **Safari-related fixes** improve sticky groups, product navigation after marking an order, short-height controls, device-local order provenance and workbook downloads. Portable HTML carries complete applicable license texts; only the font-embedding variant includes the full font license.
- **CLI review** runs for every single CSV. New interpretation flags and `--show-orders-anyway` make acknowledgement explicit; review or argument/file/output errors return exit 2. Canonical bundles have separate rules; see the [guide](../GUIDE.md).

Forecast/order formulas are unchanged by these release-preparation edits. Unknown supply remains unknown in source data; estimates may assume zero incoming, so check open purchase orders before buying. Nothing places an order or writes to your ERP.

## Validation and limits

Validation uses synthetic fixtures only. Forecast accuracy has **not been validated against real sales** or future outcomes. English and Arabic interfaces are present; inspect your own input and quantities before purchase. Existing offline Chrome and WebKit regression evidence is **not the same as a Safari hardware test**: no real Safari/iPhone hardware, live ERP/customer inventory, installed Desktop integration or hosted release was tested for this candidate. GitHub release links describe the intended download location; publication is a separate owner action.
