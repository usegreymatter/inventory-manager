# Inventory Manager v1.2.0-beta

## What’s new

- The product is named **Inventory Manager (by GreyMatter)** across the offline page, CLI, plugin and local MCP server.
- Connect Claude or Codex locally to the read-only MCP server for reorder lists, item explanations and data health. It reads one local CSV or canonical bundle snapshot at startup.
- Forecast method **Auto** is optional per product. It is experimental and has not been shown to outperform the default Current method.
- Downloadable offline pages use the Inventory Manager name. The previous Stock Runway filenames remain as redirects for existing links.

ChatGPT app connections require a remote MCP server. This beta includes only the local stdio server, so it does not include the remote server ChatGPT needs.

## Limits

Inventory Manager is free and works offline with local files. Forecasts are estimates; validate results against your own data. Nothing places or sends orders, writes to an ERP, or spends money. MCP access is read-only.
