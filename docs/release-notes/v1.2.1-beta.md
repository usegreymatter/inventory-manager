# Inventory Manager 1.2.1-beta

This beta clarifies CSV requirements and input limits, improves local MCP load errors, and fixes a duplicate row in the smart-import preview. The offline pages and client setup examples are updated.

CSV and MCP inputs support up to 10,000 products and 2 MiB. For CLI/MCP CSV input, combine daily or weekly transactions into monthly sales columns first. Browser smart import also accepts sales-by-date layouts and combines them into monthly totals. A 10,000-product file took about 25 seconds to start in one local measurement; actual startup varies.

Forecasts are estimates tested with example data, not a guarantee of real-world accuracy. Please check quantities before buying. Requests, notes and criticism are welcome: https://github.com/usegreymatter/inventory-manager/issues
