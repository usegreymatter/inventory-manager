# Inventory Manager v1.3.0-beta

A smaller first step from your spreadsheet to a draft order list. Free, offline, and no account required.

## What changed

- Excel imports one visible sheet by default; choosing a sheet really limits the import. Combining tabs requires **Add these sheets together (one sheet per warehouse)**, with hidden tabs ignored and identical copies flagged. Excel text thousands use the CSV number convention, and the browser workbook allowance supports 10,000 products × 24 monthly columns within the existing byte, row and cell limits.

- The app version stays visible with your own file loaded. **Check for a newer version** opens the releases page only when clicked; the app does not check automatically.
- **Use your own file** is the primary import action. Worklist physical quantities include their units, mixed-unit totals use a clear order-line count, and large-order warnings explain the difference between new stock being suggested and the existing-stock forecast.
- A clean preview can apply with **Use this** alone when the layout’s units have already been confirmed. Standard number-format information for an unambiguous integer CSV does not add a confirmation. Actual warnings, safety holds or new acknowledgements (including units) keep the second import confirmation.
- The local MCP server accepts **`--demo`** for the bundled synthetic sample, with a fixed default planning date. Startup errors name recognized file risks and the first duplicate product names without revealing file paths.
- The [security policy](../../SECURITY.md) explains private vulnerability reporting, scope and best-effort responses. No bounty is offered.

- **Use your own file** is beside the sample, with a three-line checklist and small downloadable CSV templates in English and Arabic headers. The examples are synthetic; replace them with your own stock and complete monthly sales. Product codes are optional when names are unique.
- The header separates **Data through** (latest sales month) from **today**. Sales more than 45 days old get a reminder to refresh the export.
- **Fix: stock counted after the last sales month.** Stock was always treated as counted at the end of the last sales month, so sales between month end and a later count were subtracted twice (orders too large, some run-out dates already in the past). Set **Stock counted on** (browser, for the loaded file only) or `--stock-date YYYY-MM-DD` (CLI, per run) and run-out, order-by and quantity start from the end of the count day. The count date is not saved as a setting, so an old date cannot carry over to newer stock. Without it nothing changes, but a warning appears when today is more than 7 days after the last sales month.
- **Print order** prepares the current full order list grouped by supplier, including missing-incoming caveats and warnings. Use your browser to print or save as PDF. Nothing is sent.
- Forecast settings lead with **Current (default)** and **Auto (experimental)**. Other existing methods remain behind **More methods**.
- Mixed-unit headline quantities use an order-line count rather than adding unlike units.
- Import explains what is needed before **Use this** becomes available, avoids duplicate warnings, and shows shared file warnings once in the import dialog. Affected worklist rows retain a compact input-warning marker, including for future-dated sales months; dismissing the summary does not remove row markers. Product-specific warnings and safety holds remain.
- The Arabic-header template is labeled **browser app**; CLI/MCP require English headers (use the English template). Missing-code errors in the browser now name candidate columns such as `Ref`, with the same rename hint as the CLI.
- The [guide](../GUIDE.md#from-odooexcel-in-5-steps) explains how to prepare Odoo/Excel stock and monthly sales in five steps, including the open-purchase-order check.

## What did not change

Forecast and reorder calculations are unchanged (the optional stock count date only moves the starting stock to the count date). Auto is still experimental, not proven better for your data. Forecasts are estimates, not purchase instructions.

The interface remains English-only; Arabic headers and product names are data support, not a translated UI. The page does not import an open-PO report or connect to Odoo. Unknown incoming is counted as 0 in purchase estimates: check existing orders before buying. Data stays in memory; reloading returns to the sample. Settings can persist locally when browser storage is available.

These notes describe the source and offline page, not a promise that hosted demos or release downloads have been updated.

## Known limits

If your sales months are later than today, check the dates before ordering. Future-dated sales can shift order dates; the warning marker does not correct the inputs or calculations.

## Feedback welcome

Try a copy of your spreadsheet, check the draft against your own records, and tell us where it is confusing. Requests, criticism and bug reports are welcome through [GitHub issues](https://github.com/usegreymatter/inventory-manager/issues).
