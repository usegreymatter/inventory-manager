# A3 candidate

A white, quantity-first product browser. A stock owner in a bright office can scan the order figure, flip through products, and inspect the stock trajectory. The core, baseline purchase-order helpers, and A2 computed series are embedded verbatim.

Build: `/usr/bin/python3 standalone/build.py --template option-a3` from the root. Open `standalone/design/option-a3.html` offline. No dependencies or server.

The sidebar groups Order now, Soon, OK and Needs data. Search matches product names and SKU codes, without case sensitivity. ArrowUp/Down, j/k and visible chevrons navigate the filtered results without wrapping. ArrowLeft/Right also select products. Search selects the first result when the previous selection is excluded; no matches retain the last chart and disable navigation. Clearing search retains the current product. `#sku=` restores selection; an explicit valid hash outside current results clears the filter. Horizontal chart swipes change product; the four segmented controls change chart range. There is no chart pan gesture in A3.

Selection preserves sidebar DOM and evaluated rows. Series are cached for each evaluated item; settings, imports and date changes invalidate the cache. Only the main panel and two selected-row attributes change on selection.

The toolbar disclosure holds CSV import, settings and purchase-order copy. Warning disclosures expose full details on tap, and have hover titles. The information disclosure holds chart assumptions and the original conditional order sentence. Arrival shows the core's confirmed monthly receipt following a supply gap; `Unknown` means none is listed. It is not a promise about an unplaced order. Charts include listed receipts and exclude suggested orders.

Run `node standalone/capture-a3.cjs` with the existing `PLAYWRIGHT_MODULE`, `CHROMIUM_EXECUTABLE`, and `TMPDIR=$PWD/.scratch` to collect real Chromium evidence. It freezes 12 Nov 2026, uses disposable contexts, blocks and records HTTP(S), and closes its browser. The performance fixture is a scratch HTML copy with only SAMPLE replaced by 500 synthetic items; timing includes core evaluation, list creation, selected SVG and layout, and excludes browser startup. The checked-in candidate always uses the original sample.

Current writer evidence and remaining proof live only in `.scratch/design/a3-writer-receipt.json` (local, not published) and `.scratch/design/a3-browser-report.json` (local, not published).
